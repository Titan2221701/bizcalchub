Cómo preparar una consulta útil

  • Incluye la URL, el nombre de la calculadora, el navegador y el idioma utilizado.
  • Describe el resultado esperado y lo ocurrido. Usa importes ficticios para demostrar un problema en lugar de cifras empresariales confidenciales.
  • Para comentarios de accesibilidad, indica el control o texto difícil de usar y la tecnología de asistencia empleada.
  • No envíes contraseñas, datos de pago, documentos de identidad ni registros financieros personales.
